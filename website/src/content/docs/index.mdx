## A whole game in one file

<p class="lede">
	`Program.cs` registers the modules and systems a game uses on the builder, adds them to the schedule on the
	application, and runs it. Everything else is a plain class with stage attributes.
</p>

<div class="ion-quickstart">

```csharp title="Program.cs"
var builder = IonApplication.CreateBuilder(args);
builder.AddEcsRendering3D().AddSystem<ModelSystem>();

using var game = builder.Build();
game.UseEcsRendering3D().UseSystem<ModelSystem>();
game.Run();
```

<ol>
	<li><strong>Add.</strong> `AddEcsRendering3D()` registers the 3D renderer, the ECS module and the engine core, and binds their options from `appsettings.json`. Modules pull in what they depend on.</li>
	<li><strong>Use.</strong> `UseEcsRendering3D()` puts those modules' steps into the schedule; `UseSystem` adds your own.</li>
	<li><strong>Run.</strong> The source generator compiles the schedule into direct calls, validates it, and the window opens. Pass `--headless` and the same file runs without a GPU, in CI or under test.</li>
</ol>

</div>

<span class="ion-eyebrow">Why Ion</span>
## Built for fast iteration and fast frames

<CardGrid>
	<Card title="Systems, not callbacks" icon="puzzle">
		A system is a plain class. Each public method with a stage attribute (`[Init]`, `[FixedUpdate]`, `[Update]`, `[Render]`) is a step. Order is explicit, validated at startup, and the whole schedule can be printed.
	</Card>
	<Card title="Generated, not reflected" icon="rocket">
		Roslyn generators compile the schedule, event bus, ECS queries, network serializers and web routes into direct calls, so games trim and publish with Native AOT.
	</Card>
	<Card title="2D and 3D rendering" icon="star">
		A WebGPU-shaped RHI over Vulkan and OpenGL ES, a batched sprite renderer with text and cameras, and a PBR 3D renderer with glTF models, shadows and instancing.
	</Card>
	<Card title="Batteries included" icon="setting">
		Audio, keyboard, mouse, gamepad and touch input, immediate-mode UI, Box2D and Bepu physics, scenes, coroutines, hot-reloading assets, metrics and Tracy tracing.
	</Card>
	<Card title="Agent-friendly" icon="laptop">
		A JSON-RPC remote protocol, the `ion` CLI and an MCP server let a coding agent run, step, inspect, screenshot and test the game it is writing.
	</Card>
	<Card title="Testable by design" icon="approve-check">
		`IonTestHost` runs your real `Program.cs` headless, frame by frame, with deterministic time, scripted input, state snapshots and golden files.
	</Card>
</CardGrid>
